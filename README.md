# DSA-lab-programs-7-12

## Executive Study & Growth Tracker

A corporate-style web application has been added in `corporate-study-tracker/` to track:

- Day-wise study and skill tasks
- Focus minutes completed per day
- Streak consistency
- Reward points and badge milestones
- A 7-day activity trend chart

### Run locally

```bash
cd corporate-study-tracker
python3 -m http.server 4173
```

Then open: `http://localhost:4173`
